# Traveling Tiger Center: Nitro Run

A top-down desert highway chase at Exit 87. The driver found a liter of nitro
instead of a Gatorade. Six lanes, no speed limit, five miles to lose the police.

Play it: https://xrecessive.github.io/tiger-nitro/

Controls: W/S throttle and brake, A/D steer across all six lanes, Shift burns
nitro, Esc pauses, R restarts, M mutes, F11 fullscreen. Pass close to traffic
for points; crash or get caught and the run is over.
